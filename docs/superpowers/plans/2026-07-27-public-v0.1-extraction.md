# Team Memory Agent Public v0.1 Extraction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an independently installable, sanitized public hub and MemberKit
whose reviewed bundles flow idempotently through a local ledger into Markdown
reports, with opt-in local reminders and no automated transmission.

**Architecture:** Reuse the proven hub and MemberKit package boundaries in a clean
public monorepo. Add a strict bundle validator/importer at the hub boundary and a
local state machine around MemberKit drafting. Keep scheduling as a thin launchd
adapter over a portable run-once command.

**Tech Stack:** Python 3.11+, SQLite, PyYAML, Requests, pytest, setuptools, macOS
launchd for the first schedule installer.

## Global Constraints

- Modify only the public checkout; the live private checkout and private company
  SDK remain read-only.
- Do not use live databases, configuration, inboxes, schedulers, or vaults.
- Do not commit, push, publish packages, or migrate production.
- Hub and MemberKit remain independently installable.
- Scheduled work may create local drafts and notifications but must never transmit.
- `teammem-bundle/v1` remains frozen and events remain authoritative.
- Tests require no network, credentials, LLM, real Git remote, or real scheduler.
